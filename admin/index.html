Painel do site Facobil

Para editar o site, entre com a sua chave de acesso do GitHub.

Como obter a chave (só uma vez)
  1. Abra Fine-grained tokens › Generate new token (com sessão iniciada no GitHub).
  2. Nome: Painel Facobil. Validade: 1 ano (ou a que preferir).
  3. Em Repository access escolha Only select repositories e selecione facobil-site.
  4. Em Permissions › Repository permissions: Contents: Read and write e Actions: Read-only.
  5. Carregue em Generate token, copie a chave e cole-a aqui.

A chave fica guardada só neste navegador. Nunca a envie por e-mail ou mensagem.
